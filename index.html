🛰️ SatTrail Predictor

1 · Session Setup

Fetch needs real internet on the host (Pi / GitHub Pages) and CelesTrak allowing cross-origin requests; if it fails, paste a TLE set manually. With the full "active" catalog (~15,000+ objects) the app first does a fast coarse scan of every satellite, then re-samples only the ones that come near your target at 0.5s resolution for accurate trail shapes and entry/exit timing — so large catalogs stay responsive without losing accuracy on the satellites that matter. An extremely brief, fast-moving pass could in rare cases slip between coarse samples and go undetected entirely; a filtered CelesTrak group reduces that risk further if it matters for your session.
