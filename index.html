AstroSat FOV Analyzer User Guide

1. Top Control Bar

Use the 📍 Use GPS button to retrieve location coordinates (falls back to Minneapolis, MN). Select your exact smart telescope (Dwarf 3, Seestar S50/S30, Vespera, Stellina, Hestia, eVscope, Odyssey) or input custom FOV degrees. Pick any Messier target (M1–M110) to scale the reticle.

2. Focal Plane FOV Canvas

Displays exact angular tick marks along horizontal/vertical axes. Trails are rendered with Liang-Barsky line vector clipping:

  • Vivid Red: Intersects central target reticle ellipse.
  • Bright Orange: Crosses telescope FOV boundary.
  • Electric Purple: Near miss within 0.5° of frame.

3. Full Night Timeline Slider

Drag the center of the cyan session window to slide across the night. Drag the left/right handles (║) to lengthen or shorten imaging duration. Ticks are set to pointer-events: none so dragging is completely smooth.

4. Sub-Exposure Efficiency Analyzer

Calculates exact clean vs corrupted sub-frame count based on selected exposure time (10s–300s) and identifies the Longest Satellite-Free Stretch with a single-click "Snap Here" button.
